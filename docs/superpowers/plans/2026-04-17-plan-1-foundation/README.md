# Plan 1 — Foundation (per-task split)

Source plan: `../2026-04-17-plan-1-foundation.md` (the master). This directory splits it into one file per task so each can be executed and reviewed independently.

**Environment deviations from the master plan (discovered during Task 1):**
- Rails 8 does **not** accept `--javascript=vite`. Vite is installed via `bundle add vite_rails` + `bundle exec vite install` instead.
- **npm is blocked globally** on this machine — use **pnpm** for all JS work. This affects Task 15 (CI) as well: swap `npm ci` for `pnpm install --frozen-lockfile`.
- **Docker / Kamal deploy is skipped** for this session (user can't run Docker). Task 14 is removed from this plan. Kamal files generated by `rails new` are left inert.
- Ruby is **4.0.2** (not 3.3). Rails 8.0.5 boots on it. `.ruby-version` reflects this.

**2026-04-20 amendment (shared topics catalog):** the design flipped from per-user topics to an admin-curated shared catalog with a `topic_subscriptions` join. Tasks 7, 9, 10, 11, 12, 16, 17 were redesigned; tasks 7b and 8b were inserted. Tasks 7–10 had been implemented under the old per-user model and are marked `pending` for re-implementation.

## Per-task convention

Every task ends with: run affected tests (`bin/rspec <scope>`) green, run `bundle exec rubocop` clean (or noted), then one commit with the message specified in the task. **Do not auto-commit when executing; ask for approval first.**
